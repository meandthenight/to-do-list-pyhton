# simple TO-Do List app (python)

Aplikasi "TO-DO List" berbasis Command Line Interface (CLI) menggunakan python.
program yang kelola tugas harian melalui terminal.

## Fitur utama

1. Add Task -> Menambah tugas baru ke dalam daftar.
2. View Task -> Melihat semua daftar tugas beserta statusnya.
3. Mark as done -> Menandai status tugas yang sudah selesai
4. Delete task -> Menghapus tugas dari daftar.
5. Exit -> Keluar dari program.

## Cara menjalankan

1. Pastikan Python 3 sudah terinstal.
2. Buka terminal di folder proyek.
3. Jalankan perintah:

bash
python To_Do_List.py
